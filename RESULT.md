# Result Take Home Test

## Cara menjalankan project

1. Jalankan command `pnpm install` atau `npm install` untuk install node package
2. copy file `.env.example` ke `.env`, lalu ubah sesuai value pada mockup-api
3. Jalankan command `pnpm dev` agar sistem dapat dijalankan di local

## Apa saja yang sudah diselesaikan

1. Menyelesaikan test sesuai dengan aturan yang telah ditetapkan pada `README.md`
2. menambahkan tampilan keranjang, supaya terdapat interaksi pada simulasi keranjang yang disertai apply voucher
3. Menyelesaikan dokumentasi penggunaan AI dan menjawab decisions.md

## Apa saja yang belum sempat dikerjakan

1. Belum menambahkan animasi pada tampilan
2. belum memberikan error handling yang lebih pada voucher validation, cuman sudah ada yang dasar
3. belum membuat responsive
4. Belum membuat unit test
